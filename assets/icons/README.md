# Game icons

Icons in this folder are a curated subset of **game-icon-pack** by Nieobie,
released under **CC0 1.0 Universal** (public domain dedication — no attribution
required, commercial use permitted).

- Source: https://github.com/Nieobie/game-icon-pack
- Licence: https://creativecommons.org/publicdomain/zero/1.0/

Files were taken from `svg/no-padding/` and renamed to their role in the app
(e.g. `3-gear/bullet.svg` -> `bullet.svg`). Every icon carries
`fill="currentColor"`, so it inherits the surrounding CSS `color` and themes
itself against the palette in `css/base.css`.

Credit is not legally required under CC0, but it is recorded here because the
work deserves it.
